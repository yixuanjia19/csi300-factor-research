# 沪深 300 成分股的动量与低波动因子研究

使用 2018–2025 年的复权日线和沪深 300 历史成分区间，
检验 12–1 月动量与 60 日低波动因子对次月收益的预测表现。
2018 年用于积累因子计算窗口，最终得到 83 个可检验的月度截面。

## 主要发现

- 动量与低波动的月均 Rank IC 分别为 0.0390 和 0.0507。
- 动量最高组较最低组月均领先 1.136 个百分点，剔除 2020 年后为 0.598 个百分点。
- 高动量组合的年化毛收益为 14.88%，同股票池等权组合为 8.55%。
  高动量组合的月末最大回撤也更深，分别为 35.38% 和 30.07%。
